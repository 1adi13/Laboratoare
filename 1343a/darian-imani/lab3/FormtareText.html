Formatarea textului cu CSS

Această pagină prezintă indicațiile pentru formatarea textului folosind CSS.

Pagina de pornire

În folderul lab3 se creează o pagină index.html cu linkuri către paginile laboratorului și către pagina personală.

Stiluri inline

Stilurile inline se scriu direct în atributul style al elementului HTML. 

<p style="color: green;">Text verde</p>

Stiluri interne

Stilurile interne se scriu în tagul <style>, în interiorul secțiunii <head>. 

<style>
p {
    color: green;
}
</style>

Stiluri externe

Stilurile externe se scriu într-un fișier separat, de exemplu myStyle.css. 

<link rel="stylesheet" href="myStyle.css">

Linkuri ca butoane

Linkurile pot fi afișate ca butoane folosind proprietăți CSS precum background-color, padding, border-radius și text-decoration.
